## Features

- Download the application once; subsequent updates can be installed from within the program.
- Fully automated farming for EXP stages, Thread stages, and Mirror Dungeon (Normal and Hard).
- Semi-automated support for P-button combat.
- Team rotation after tasks finish, so settings do not need to be edited repeatedly; supports selecting multiple team archetypes.
- E.G.O Gift blacklist and whitelist.
- Automatic Enkephalin purchasing and conversion.
- Detailed logs make it easy to inspect what the application did.
- Adjust theme-pack card weights through a graphical interface.
- Unzip and run—no environment setup required.
- What you see is what you get; getting started is intended to be straightforward.
